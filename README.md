# Відвоювання — чотири нові кампанії

Готовий до відкриття Godot-проєкт міститься в **`zombie_game_3d_v3/`**.
Оригінальний архів `96.zip` збережений без змін як вихідна версія.

## Запуск

1. Встановіть Godot 4.4.1 або сумісну версію Godot 4.
2. Імпортуйте `zombie_game_3d_v3/project.godot` і натисніть **F5**.
3. На карті прокрутіть до чотирьох нових гілок під старим регіоном.
   Коліщатко змінює масштаб, перетягування пересуває карту.

Гра має **47 карт**. Нові кампанії:

| Кампанія | Карти | Механіки |
|---|---|---|
| Чорний приплив | loc28–32 | Припливи й сухі настили, осередки потопельників, відновлення маяка, Адмірал потонулих |
| Хор порожніх дзвонів | loc33–37 | Руйновані дзвони, видимі хвилі резонансу, тимчасове підсилення мерців, Без’язикий дзвонар |
| Скляна ніч | loc38–42 | Руйновані пластини, слабкі двійники, обмежене породження копій, відкладені повтори ударів, Король без відображення |
| Залізний мор | loc43–47 | Преси, руйновані приводи, конвеєри, пастки проти мерців, Зшитий машиніст |

Кожна кампанія складається з п’яти окремих карт. За звичайних умов
перші карти відкриваються після `loc27`, наступні — після попередньої
карти відповідної кампанії. У вихідній грі вже ввімкнений режим
**`GameState.OPEN_ALL_LOCATIONS = true`** для перегляду всіх карт;
його збережено. Для послідовного проходження встановіть `false`
у `game_state.gd`. Куплене спорядження і справжній прогрес це не підміняє.

Жовті ромби на мінікарті позначають руйновані цілі. Бийте їх звичайною
зброєю. Цілі не зараховуються як зомбі й не дають монет. На картах із
обов’язковими цілями перемога потребує і їх виконання, і завершення хвиль.
На маяку потрібно провести 45 секунд у позначеному подвір’ї.
Старі збереження `user://save_v3.json` залишаються сумісними.

Керування: WASD — рух; ЛКМ/Пробіл — атака; 1–5, Q/E або коліщатко —
зміна зброї; Esc — пауза. Куплені ривок і стрибок працюють як раніше.
Нові карти не вимагають цих навичок або певної стихійної зброї.

## Відтворювана перевірка (Linux x86_64)

```bash
./scripts/setup-godot.sh
./scripts/test-campaigns.sh
```

Скрипт встановлення завантажує Godot 4.4.1 у локальну `.tools/`,
не змінюючи системну версію рушія. Перевірки використовують окремий
тимчасовий каталог даних і не перезаписують збереження гравця.

- Тест даних порівнює 27 старих локацій з `96.zip`, перевіряє нові
  гілки, біоми, ворогів, босів, хвилі, іконки та розблокування.
- Runtime-тест відкриває всі 20 нових карт, перевіряє атаки по цілях
  і мерцях, механіки, паузу, умови перемоги, поразку, повторний вхід
  і збереження. Це автоматична перевірка станів, а не повне ручне
  проходження всіх хвиль або остаточне балансування складності.
- `tests/capture_campaigns.tscn` запускає справжній бій і перевіряє
  удар по цілі та паузу з візуальним знімком. Приклад:
  `godot --path zombie_game_3d_v3 --rendering-method gl_compatibility res://tests/capture_campaigns.tscn -- loc30`.

Повний опис початкової гри: [`zombie_game_3d_v3/README.md`](zombie_game_3d_v3/README.md).
