ЯК ПІДКЛЮЧИТИ СВІЙ ШРИФТ
Покладіть .ttf / .otf (ОБОВ'ЯЗКОВО з кирилицею) у цю папку, з будь-якою назвою. Потім відкрийте проєкт у Godot і зачекайте,
поки редактор імпортує файл (смужка внизу праворуч). Запустіть гру — шрифт буде в усій грі.
  • Один свій шрифт  -> шрифт УСІЄЇ гри (меню, карта, бій, підказки, цифри урону).
  • Два шрифти: файл з «royal» у назві (royal.ttf) — королівський/золотий і основний; з «dark» (dark.ttf) — зловісний
    (назви локацій, складність, повідомлення бою, ПОРАЗКА).
Вибір шрифтів — game_fonts.gd, застосування на всю гру — font_boot.gd (автозавантаження).

Вбудовані запасні (працюють, поки свого шрифту немає):
Lora Bold, SIL OFL 1.1 — основний; Arsenal SC, SIL OFL 1.1 (ArsenalSC-OFL.txt) — запасний «зловісний».

Найпростіше: киньте сюди ОДИН .ttf з кирилицею (наприклад CormorantSC-Bold.ttf) під будь-якою назвою — він стане шрифтом усієї гри.
